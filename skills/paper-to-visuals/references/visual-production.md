# 视觉制作指南

在已理解原文、开始设计首页简图与弹窗详细图解时阅读本文件。

## 分镜简稿

每张图用简短记录确定以下内容，记录可以保存在工作材料里，无需逐项向用户索取确认：

- **这张图回答什么**：一个明确问题。
- **模板位置与小项**：所属的阅读框架部分、01–0n 导览章节及本图覆盖的小项；同一部分拆章时记录后续小项的去向。
- **看完应理解什么**：一句准确结论。
- **画什么**：具体对象、动作或变换，以及它们的关系。
- **保留哪些字**：精确标题、标签、数字、单位与必要条件。
- **根据什么画**：所读版本、章节、公式或图表位置。
- **哪些是示意**：自行构造的样本、布局、类比与作者报告结果的边界。

若简稿只有几个抽象名词，把每个名词换成可识别的对象或一次具体操作，再决定连线。

## 首页简图与弹窗详细图

首页用一个具体对象或关键关系帮助用户定位本章，弹窗增加理解所需的细节。例如首页“基线比较”只画共享输入和两条路径；弹窗进一步展开各自输入、可替换模块、输出和评判依据。
为各章分别设计简图与详细图；详细图可以包含多段、可切换步骤或一张清楚的放大图，不要求整篇采用相同的画法。
不要将大幅细节图缩小到首页，再在弹窗原样展示，宣称已实现两层讲解。首页可以用详细图的局部或摘要，但弹窗应有实际增量内容。

## 弹窗里的阅读卡形式

沿用用户模板的分区与顺序，用精简内容填入对应小项：

- 顶部保留导航编号、章节名和所属阅读部分，例如“04 基线怎样比较｜研究设计与方法”。
- 小项用短标签定位，图形展示关系；例如“数据来源／规模”可组成信息栏，“主要方法”用主体流程，“对照／指标”用侧边短卡。
- 一张卡内的多个小项共同回答该章节的主问题。布局依据内容选择，不要求每个小项都变成一个相同方框。
- 可保留简短要点、必要的小型表格和信息栏；图形应帮助解释内容，避免把长篇笔记直接缩进画布。
- 对应字段未知时用准确状态标识；研究背景或原文缺失时保持缺项可见，不用装饰性示意填补事实。
- 基本信息或结果证据需要较多文字时，可在弹窗分块或新增导航章节。连贯解释放在配套 Markdown，但图片中的必要条件仍需可见。少字通过压缩表达和分层实现，不能删去用户指定的小项。

## 让图本身解释内容

| 要解释的内容 | 可优先考虑的表达 | 需要避免的误导 |
|---|---|---|
| 研究问题 | 同一个具体场景中的障碍和期望状态 | 用抽象口号代替问题 |
| 方法 | 一个输入样本经过关键变化，得到输出 | 所有模块只有缩写和方框 |
| 新增贡献 | 已有过程与新过程对齐，突出差异环节 | 把所有环节都标成创新 |
| 实验设计 | 对齐的实验组或两条路径，显示控制变量 | 隐去影响可比性的条件 |
| 结果 | 准确的小型图表或原文实际观察的对照 | 编造曲线、夸张坐标或虚构样例 |
| 公式 | 变量对应对象、操作与变化，再给必要公式 | 用类比代替公式的成立条件 |
| 局限 | 适用边界、未验证区域与条件标记 | 将未验证画成失败或将相关画成因果 |

对于图论、理论推导、医学或其他领域，优先采用该领域能准确表示关系的图形，不强加通用 AI 模块。

## 把基线设置画成一次可理解的比较

“对照组／基线方法”需要让读者看到比较怎样发生。先按实验问题分组，再为每组确定：

1. **共同设置**：在什么任务、样本或环境中比较；只写原文确认共用的条件。
2. **改变的部分**：替换了哪个模型、组件、信号或处理，具体比较对象是谁。
3. **判断依据**：比较哪种输出或行为，依据什么参照、指标和方向判断。

用同一输入分叉、对齐的两条路径或相同流程中的可替换模块，突出改变的位置。基线名称放在对应模块内；图形应使不认识这些名称的读者仍能看出比较的是评分、控制、学习或其他能力。

- 共用条件画一次或以同形同色重复，变化部分用明确标签和强调色标出，输出连接到相应指标。
- 不同实验分别画。例如离线评分、在线选动作、训练后评测需要各自的比较路径；不同任务或算法不能因共享一个指标而合成互相对比的组。
- 原文只说明同一评测集时，不补成相同输入帧数、提示词、训练预算或完全控制的实验。未交代而影响可比性的条件保留待确认状态。
- 外部方法比较与删去组件的消融分别标识；“加一个信号”也要显示基线已有的信号，避免画成完全没有反馈。
- 对照与条件／指标在视觉上对应，同时保留各自小项标题。空间不足时把比较过程展开为独立章节或弹窗分块，不能退回只有名称的列表。
- 设置图不画未经报告的优劣柱状图、轨迹或成功／失败结果。若用具体场景解释指标，标明场景为示意。

## 默认视觉取向

- 浅色背景、充分留白、清楚的视觉层级；具体场景和流程优先于装饰。
- 使用少量主色，并为贯穿整组图的角色固定颜色；有含义的颜色同时用标签或形状说明。
- 横向流程可用横幅，单个概念可用方图或竖图，按内容选择。避免把多张图拼进一张很长或很密的海报。
- 标题通常约 8–16 个中文字符，标签通常约 2–10 个；术语较长时保持准确，可把解释放图注。
- 简单图的主体文字通常以约 40–100 个中文字符为起点；模板细节卡不设硬性字数上限，以小项覆盖和正常预览可读为准。必要的限定词、单位、比较条件不能为满足字数而删除。
- 对比对象尽量保持相同尺度、视角和顺序。把用户需要注意的变化突出一次，不用多种视觉装饰重复强调。
- 提高分辨率不能替代减少密度。正常聊天预览时仍难读的文字应删减、外移或分图。

## 图像生成说明

给当前可用的内置图像生成工具提供已经核实的内容，可采用以下说明结构；按需要填写，不携带空字段：

```text
用途：中文论文阅读图解；本张要解释的一个问题。
模板位置：总览或第几个细节部分；列出本图必须呈现的小项与已知缺项状态。
依据：仅使用以下已核实事实，不增加论文未报告的模块、数据或结论。
画面主体：具体对象，以及各对象应如何变化或关联。
构图：视觉阅读顺序、对象位置、对照关系和需要高亮的关键差异。
统一约定：与同组图片一致的角色、颜色、符号和术语。
准确文字：逐项列出图上允许出现的标题、标签、数字与单位。
必要标识：示意、预测、实际观察、作者主张或未验证等适用标签。
风格：少字、清晰、简洁科学插画、留白充分，主要标签在聊天预览中可读。
约束：不新增数据，不虚构实验图像，不增加长段文字，不使用未经解释的装饰性箭头。
```

提示词中描述科学事实必须基于已经读取的材料，不能把“请自行准确总结论文”当作阅读步骤。
生成图里的文字和关系仍需核对，提示词正确不代表成图正确。

## 精确图表与公式

结果图需要准确坐标、数值或误差线时，用标准绘图工具依据核实的数据制作。
保存数值及来源；如果只能读到原始曲线而不能准确取得数据，可使用原图局部并标注来源，或画无虚构数值的定性说明。
对裁剪或简化后的原图保留必要轴、图例与比较条件。
结构图或公式也可直接制作成矢量图并导出 PNG；如需编辑已经生成的插画，使用相应图像编辑工具，不用数值绘图流程冒充图像编辑。

## 成图检查

实际打开每张图，以正常预览尺寸检查：

1. 读者能否找到唯一的主要阅读顺序和解释重点。
2. 中文、术语、数字、单位和公式是否正确，是否有漏字、重字或字符损坏。
3. 图形、线条和箭头是否表达了原文支持的关系。
4. 示例、生成预测、真实观测、作者主张、解释性推断是否可区分。
5. 核心发现是否保留了影响其含义的对照、条件和局限。
6. 模板小项是否有可见内容或缺失状态；拆页后是否仍能追踪到对应位置。

针对错误修订对应图片，保留已经正确的关系和术语。若反复发生文字拥挤，优先减少内容或拆图。
不能用仅检查图片文件存在、像素尺寸或脚本成功替代实际视觉核对。
